## What I Focus On

**Software Architecture** — I design systems with long-term maintainability in mind. Clean architecture, SOLID principles, and clear separation of concerns across mobile and backend.

**iOS Engineering** — Native Swift development with a focus on performance, accessibility, and clean code. From UIKit to modern SwiftUI and async/await concurrency.

**Distributed Systems** — Event-driven architectures with Kafka, containerized workloads on Kubernetes, and resilient microservices in Go.

**Full-Stack Delivery** — When needed, I go end to end — Go or Node backend, Vue or React frontend, deployed and monitored in production.
